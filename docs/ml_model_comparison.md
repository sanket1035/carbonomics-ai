# Weekly forecast: model comparison

Data: 52 weeks of SYNTHETIC weekly electricity and generator diesel, calibrated to the
real monthly totals of 2025 (see `docs/weekly_synthetic_forecast.md`).

Design: targets are activity (kWh, litres), not emission. Features are past-only
(lag 1/2/4 weeks, 4-week rolling mean) plus month and ISO week. Split is time-based:
38 training weeks, 10 test weeks. Emission is computed afterwards as activity x factor.

Models: Random Forest, XGBoost. Baselines: naive last week, training mean.
Metrics: MAE, RMSE, R2. Latest numbers are in `outputs/forecast/weekly_metrics.csv`
and are regenerated by `python scripts/run_pipeline.py`.

Reading the results: the within-month pattern of the data is set by the generator, so
a good score only shows that the pipeline works. With 38 training weeks the tree
models do not reliably beat the naive baseline; that is expected and is reported as is.
Real weekly data is needed for any claim about real forecasting accuracy.

The earlier comparison (R2 0.9992 predicting `Total_Emissions` from its own activity
columns on a random split) was removed: that target is an exact formula of the inputs
(a plain linear regression reaches R2 = 1.0), so the score said nothing about forecasting.
